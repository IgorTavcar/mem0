mem0 — the memory layer for AI agents

An intelligent, persistent memory layer for AI assistants and agents. This wiki is a condensed, cross-linked knowledge graph of the entire mem0ai/mem0 codebase — architecture, the engine, the new retrieval algorithm, every provider layer, the SDKs, servers and ecosystem.

Apr-2026 algorithm Apache-2.0 Python + TypeScript Self-hosted & hosted Polyglot monorepo

Start with Architecture for the big picture, follow the Data Flow to see add() and search() end to end, then dive into the Memory Algorithm — the single-pass, ADD-only extraction with multi-signal retrieval that drives the headline benchmark numbers below.
